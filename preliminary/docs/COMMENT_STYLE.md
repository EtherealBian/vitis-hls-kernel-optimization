# 中文注释规范

## 1. 适用范围

详细中文注释适用于四个参赛优化核心文件和三个复现脚本。AMD 上游依赖文件保留原始注释，避免制造非原创署名或无意义的大规模格式变更。

## 2. 文件头

参赛优化文件在 AMD/Xilinx 原始版权声明之后标注：

```text
项目：赛题与算子名称
项目作者：Ethereal
优化与中文注释维护：Ethereal
上游来源：对应的 AMD Vitis Library
```

原始版权、Apache-2.0 声明和原作者信息不得删除或覆盖。

## 3. 正文注释

正文注释应说明“为何这样实现”和“综合后得到什么硬件”，而不只是复述代码：

- 函数注释说明输入输出流、结束标志、模板参数和调用阶段。
- 变量注释说明位宽、符号、定点格式、位域和生命周期。
- 循环注释说明迭代对象、依赖关系、展开/流水化目标及资源代价。
- HLS pragma 注释说明其对 II、延迟、并发、存储端口和资源映射的作用。
- 状态机注释说明进入条件、输出字节和退出条件。
- 数学近似必须说明适用范围、误差风险和验证要求。
- 边界条件必须覆盖空输入、尾块、填充、偏移范围、终止标志和数据顺序。

正文直接使用规范中文说明，不添加额外的作者标签前缀。

## 4. 注释与逻辑隔离

注释整理不得顺带改变算法、pragma、常量、接口和数据格式。若确需修改逻辑，应单独提交并提供仿真、综合或等价性证据，方便评审区分“文档变更”和“功能变更”。
