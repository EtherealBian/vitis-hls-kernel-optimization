# 开源范围与许可边界

## 已公开内容

- 三道赛题的最终 HLS C++ 优化文件
- 对应的优化前基线文件
- 复现所需的 AMD Vitis Libraries 支撑头文件
- 测试程序、数值/文本样例和 HLS Tcl 脚本
- 最终 C 仿真、C 综合和 C/RTL 协同仿真结果
- 中文架构图、算法说明、文件索引与复现说明

## 未公开内容

- 参赛承诺书及可能包含个人签名或身份信息的文件
- 完整提交报告、原始演示文稿和过程性 LLM 对话记录
- Vitis HLS `.prj/`、Vivado 缓存、对象文件、可执行文件和自动生成 RTL
- 与三道赛题无关的 AMD Vitis Libraries 模块

自动生成 RTL 可通过仓库中的 `run_hls.tcl` 重新得到。省略这些产物能减少仓库体积，也避免将特定工具版本生成的中间表示误认为人工维护源码。
